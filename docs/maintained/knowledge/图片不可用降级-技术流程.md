# 图片不可用降级 · 技术流程

> 所属业务线：交付保障。证据：`provider/entities.py`(+30)、`openai_source.py`(+97)、
> `image_input.py`(+30)、`astr_main_agent.py`(+152/-27)、`tool_loop_agent_runner.py`。

## 1. 目标与范围

给出 `IMAGE_INPUT_UNAVAILABLE_*` 契约的四阶段判定链、触发条件、状态复位规则与失败边界。

## 2. 契约（`astrbot/core/provider/entities.py`）

```python
IMAGE_INPUT_UNAVAILABLE_MESSAGE = "当前看不到图片，请重新发送。"      # → completion_text（用户可见）
IMAGE_INPUT_UNAVAILABLE_NOTICE  = (                                   # → content block（模型可见）
    "[Image unavailable: no visual evidence was received. "
    "Do not infer or describe the image from history, filenames or surrounding text. "
    f"Reply only: {IMAGE_INPUT_UNAVAILABLE_MESSAGE}]")

ProviderRequest.image_input_unavailable: bool = False
LLMResponse.image_input_unavailable:     bool = False
```

> `NOTICE` 内嵌 `MESSAGE`（f-string）→ 改文案会同时改模型指令，属隐式耦合。
> `"<image_caption>"` 标记在 **5 处**硬编码，无共享常量（P4）。

## 3. 四阶段判定链

| 阶段 | 位置 | 相对 `on_llm_request` | 动作 |
|---|---|---|---|
| ① | `astr_main_agent._ensure_img_caption(preserve_native_images=False)` | **之前**（在 `build_main_agent` 内） | 描述失败 → `req.image_input_unavailable=True`；`req.func_tool=None`；追加 `NOTICE`；`req.image_urls=[]` |
| ② | 存量插件的 `on_llm_request` | 钩子中 | 有图/描述 → 复位 `False` 并**过滤掉** `NOTICE` 部件 |
| ③ | `image_input.prepare_request_images` | **之后** | 重算 `has_visual_input` / `has_caption` → 写 `req.image_input_unavailable` 与 `_enhance_visual_unavailable` |
| ④ | `openai_source.text_chat` / `text_chat_stream` / 转换层 | provider 调用期 | 补追加 `NOTICE`；历史回读判定；产出固定文案 |

### 阶段①细节

```
try:
    caption = await _request_img_caption(...)       # 内部：llm_resp.image_input_unavailable is True → raise ValueError
    if not caption.strip(): raise ValueError
    req.extra_user_content_parts += TextPart(f"<image_caption>{caption}</image_caption>")
    req.image_input_unavailable = False
except Exception:
    if preserve_native_images and req.image_urls:
        req.image_input_unavailable = False; return   # 保留原生图
    req.image_input_unavailable = True
    req.func_tool = None
    req.extra_user_content_parts += TextPart(IMAGE_INPUT_UNAVAILABLE_NOTICE)
finally:
    if not preserve_native_images: req.image_urls = []
```

### 阶段④触发条件（三选一）

| 触发 | reason | 前置守卫 |
|---|---|---|
| `"The model is not a VLM" in str(e)` | `model_not_vlm` | `not image_fallback_used and self._context_contains_image(context_query)` |
| `_is_content_moderated_upload_error(e)` | `image_content_moderated` | 同上 |
| `_is_invalid_attachment_error(e)` | `invalid_attachment` | 同上 |

回退动作：
```
new_contexts = _remove_image_from_context(context_query)   # deepcopy 去图；空内容补 NOTICE
new_contexts.append({"role": "system", "content": IMAGE_INPUT_UNAVAILABLE_NOTICE})
payloads["messages"] = new_contexts
payloads.pop("tools"); payloads.pop("tool_choice"); payloads.pop("parallel_tool_calls")
func_tool = None
```

短路点三处：`text_chat` 前置（在设置 `tool_choice` 之前）、`text_chat` 重试耗尽后、`text_chat_stream` 前置。

### 历史回读判定

```
def _context_has_unavailable_image(contexts):
    for context in reversed(contexts):          # 只看最近一条
        if context.get("role") != "user": continue
        content = context.get("content")
        if not isinstance(content, list): return False        # 纯文本简写格式 → 直接返回
        if any(part 是 image_url 或 含 "<image_caption>"): return False   # 新一轮有图 → 复位
        return any(part.get("text") == IMAGE_INPUT_UNAVAILABLE_NOTICE)
    return False
```

### 流式缓冲重放

```
buffer_images = image_fallback_used or self._context_contains_image(context_query)
async for response in self._query_stream(...):
    if buffer_images: buffered_responses.append(copy.deepcopy(response))   # _query_stream 复用同一 chunk 对象
    else: yield response
if image_fallback_used:
    usage = next((r.usage for r in reversed(buffered_responses) if r.usage), None)
    yield self._unavailable_image_response(usage)      # 整体替换为固定文案，保留 token 统计
else:
    for response in buffered_responses: yield response
```

## 4. 状态与幂等

| 规则 | 实现 |
|---|---|
| 复位条件 | 出现原生 `image_url` **或** `<image_caption>` → `image_input_unavailable=False` |
| 不延续 | 历史失败标记只在"最近一条 user 消息无图无描述"时生效 |
| 降级只发生一次 | `image_fallback_used` 守卫，防递归降级 |
| 工具摘除一致性 | `entities` 转换方法 / `_ensure_img_caption` / `_fallback_to_text_only_and_retry` **三处**都置 `func_tool=None` |

## 5. 异常与边界

| 场景 | 行为 |
|---|---|
| `preserve_native_images=True` | **core 内无生产调用点**（仅测试使用）→ 死参数 |
| 阶段①③与插件②竞写同一字段 | 最终值取决于阶段③的重新判定，插件复位可能被覆盖 |
| `if not isinstance(content, list): return False` | 与 `continue` 混用，语义微妙，易误改 |
| 无日志 | 阶段④新增分支**零日志**，降级不可观测 |
| deepcopy 开销 | 图片场景每个 chunk 深拷贝；缓冲使流式失去实时性 |
| 厂商错误文案硬匹配 | `"The model is not a VLM"` / `"download attachment"` / `"404"` / `"invalid_attachment"` 脆弱 |
