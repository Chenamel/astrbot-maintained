## 3. 状态与幂等

| 状态 | 迁移 |
|---|---|
| `DirectTurn.version` | `observe` 每收一条 +1；`collect` 通过 `version == turn.version` 判定是否已被取代 |
| `owner` | `collect` 关闭回合时确定；`is_current` 比较 `event is turn.owner` 且版本一致 |
| `closed` | 静默/超时后置 True；`finish` 清理 |
| `sent` | `mark_sent` 置 True；此后 `observe` 不再接纳新消息 |
| `tools[key]` | `begin_tool` 占位 → `record_tool_result` 落结果 → `release_tool` 释放；`wait_tool_result` 超时 15s |

**幂等约束**：`(tool_name, normalized_params)` 在一个回合内至多真执行一次；跨回合通过结果槽位复用。

**失效判据（单一真相）**：`is_current(event)` = 未被 `_turn_superseded` 且 `_direct_turn_version == turn.version` 且 `not turn.closed`；**事件不属于任何回合时返回 True**（非目标平台自然短路）。

## 4. 异常与边界

| 场景 | 行为 |
|---|---|
| 回合状态字典泄漏 | 仅靠 `first_at + max_wait_sec` 被动过期，无 TTL 兜底（R2） |
| `finish` 未调用 | `scheduler` 用 `finally` 保证调用（在 `cleanup_temporary_local_files` / `unregister` 之前） |
| 取消不彻底 | provider 不响应 `stop_event` 时 token 仍消耗，产物被 `is_current` 丢弃 |
| `stale_reserved_tool` | abort 但仍 `yield await next_result_task`，保证已启动操作完成一次 |
| 逐组件发送中途失活 | **已发出的组件无法回滚** → 可能产生半截消息 |
| `collect` 在非目标平台 | 第一行 `eligible()` 短路返回 True（设计正确但注释缺失） |
| 并发 | `changed` Event 与 `version` 无锁，依赖"无 await 临界区"隐式假设（R4） |
