## 三条业务线的由来

这 1639 行不是三块互不相干的功能，而是**同一场故障的前因后果**：

```
① 直报回合（底座）
   同账号连发 N 条 → 旧轮次仍在跑 → 副作用工具被重跑、旧结果污染新轮次
        │  需要：轮次版本 + 在途取消 + 工具结果复用
        ▼
② 交付保障（用户可见质量）
   模型只给描述不给源码 / 工具同参反复失败刷屏 / 发图但看不到图却硬编内容
        │  需要：交付修复、失败熔断、图片不可用确定性降级
        ▼
③ 维护保护与执行授权（自保与安全）
   打过的补丁被上游覆盖 → 机器人整插件挂掉
        │  需要：维护名单闸门（拦不住启动器，见 §风险）
```

## 维护约定
